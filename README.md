# 🤫 Don't Wake The Baby

> A wave-based action-defense game featuring GOAP AI architecture and dynamic sound mechanics, built with Unity.

Welcome to the **Don't Wake The Baby** repository! This project is a unique blend of combat, inventory management, and stealth/sound-control mechanics. The core objective is to survive enemy waves and defend the environment without generating enough noise to wake the sleeping baby. 

The codebase showcases advanced AI implementations, utilizing both **GOAP (Goal-Oriented Action Planning)** and robust State Machines to create unpredictable and intelligent enemy behaviors.

---

## 🧠 Advanced AI Architecture (GOAP)

Unlike standard hardcoded behaviors, this project implements a modular **Goal-Oriented Action Planning** system. This allows AI agents to dynamically formulate action plans based on current world states and their specific goals.

* **Core GOAP Classes:** `GAgent`, `GAction`, `GPlanner`, `GWorld`, `WorldStates`.
* **Dynamic Decision Making:** Agents evaluate the cost and requirements of actions (e.g., `GoToBaby`, `GoToRoom`) and queue them dynamically to achieve their primary objectives.
* **State-Driven Enemies:** Alongside GOAP, varied enemies utilize State Machines (`EnemyStateMachine`, `BombEnemyStateMachine`, `babyEnemyStateMachineScript`) for fluid combat and movement states.

## ⚙️ Core Gameplay Systems

The project is structured to handle multiple interacting systems seamlessly:

| System | Description | Key Classes |
| :--- | :--- | :--- |
| **Sound / Stealth Mechanic** | Tracks noise levels generated by combat and actions to prevent waking the baby. | `BabySoundBar`, `BabySoundUpdate` |
| **Wave Management** | Controls enemy spawning, wave progression, and difficulty scaling. | `WM_script`, `Wave_State`, `Spawn` |
| **Combat & Interactions** | Handles melee (`Sword`) and ranged (`Bullet`) combat, alongside object destruction. | `PlayerHealth`, `EnemyAttack`, `EnemyBreakingObject` |
| **Input Handling** | Implements the modern **Unity Input System** for responsive and cross-platform controls. | `Input_Manager`, `Input.inputactions` |
| **Economy & Inventory** | Manages in-game currency, item holding, and UI representation. | `Money`, `UIInventoryManager`, `Placeable` |

---

## 🛠 Technical Details & Developer Notes

* **NavMesh Integration:** Enemies and agents utilize Unity's NavMesh for pathfinding, dynamically updating routes (`NavMeshDynamicUpdate`) to avoid obstacles and navigate complex room layouts (`GoClosest`, `FindClosest`).
* **Modular UI:** The inventory and health systems are decoupled from core gameplay, communicating via UI Managers (`UIInventoryItem`, `PlayerHealthUIScript`) for a clean architecture.
* **Interactable Environment:** Players can interact with environment objects (`Fridge`, `radiohead`) and utilize tactical items (`Fence`, `Placeable`) to defend against enemy waves.
